### Extra Features
Note these "features" are more quality of life improvements than actual exciting features;

- "Clear Results" link to clear the applied filter
- "Order By" to order the results Ascending or Descending 
- "Status Filter" interactive legend colour boxes to view only birds by that status
- "Enlarged Bird Card" bird card fits the screen, so when the window is set to half the screen it shows a single line column of enlarged bird cards
- "Hover Effect" bird cards hover with a shadow when you mouse over them
- "Back to top button" simple arrow icon that will smoothly scroll the user back to the top of the website
